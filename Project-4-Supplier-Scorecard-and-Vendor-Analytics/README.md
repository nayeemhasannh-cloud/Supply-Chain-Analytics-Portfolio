# Supplier Scorecard and Vendor Performance Analytics

## Overview

This project develops a supplier performance evaluation framework using procurement and vendor management KPIs. The objective is to measure supplier effectiveness, identify high-risk vendors, and support strategic sourcing decisions.

## Business Problem

Organizations rely on suppliers for quality, delivery reliability, and cost efficiency. Poor supplier performance can increase procurement costs, delays, and operational risk.

This project creates a data-driven supplier scorecard to evaluate and rank supplier performance.

## Key Performance Indicators

- Average Lead Time
- On-Time Delivery Rate
- Defect Rate
- Fill Rate
- Contract Compliance
- Sustainability Score
- Average Cost per Unit
- Total Procurement Spend
- Overall Supplier Performance Score

## Supplier Scoring Framework

Supplier KPIs were combined into an overall performance score and used to classify suppliers into performance categories.

### Supplier Categories

- High Performers
- Medium Performers
- Low Performers
