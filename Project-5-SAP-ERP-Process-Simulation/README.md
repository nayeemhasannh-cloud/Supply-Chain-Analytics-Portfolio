# SAP ERP Procurement and Supply Chain Process Simulation

## Overview

This project demonstrates ERP-driven supply chain management by combining inventory performance analytics with SAP ERP process simulation.

The project models key supply chain transactions and evaluates operational performance across procurement, inventory management, sales, and revenue generation activities.

## Module 1: Inventory Performance Analysis

### Business Problem

Organizations need visibility into inventory efficiency, stock availability, and supplier responsiveness to maintain operational performance.

### KPIs Calculated

- Total Demand
- Inventory Turnover
- Average Inventory Turnover
- Fill Rate
- Stockout Rate
- Average Lead Time

### Analytics Performed

- Demand Trend Analysis
- Inventory Efficiency Analysis
- Lead Time Monitoring
- Stockout Analysis
- Inventory Performance Evaluation

### Visualizations

- Demand Trend Line Chart
- Inventory Turnover Trend
- Lead Time Trend
- Stockout Occurrence Analysis
- High Stockout Month Identification
- Inventory Efficiency Monitoring

## Module 2: SAP ERP Process Simulation

### Business Problem

Supply chain operations require integration between procurement, inventory management, sales, and financial processes.

This simulation demonstrates how ERP systems connect these activities through end-to-end business workflows.

### ERP Processes Simulated

#### Procure-to-Pay (P2P)

- Procurement Request
- Purchasing Activity
- Goods Receipt
- Payment Processing

#### Order-to-Cash (O2C)

- Customer Orders
- Sales Processing
- Delivery Execution
- Revenue Collection

#### Inventory Management

- Opening Stock
- Purchases
- Units Sold
- Closing Stock
- Stock Health Monitoring

### KPIs Generated

- Total Procurement Cost
- Total Revenue
- Units Purchased
- Units Sold
- Inventory Status
- Procurement Status
- Delivery Status
- Payment Status

### Dashboard Features

- Procurement Performance Monitoring
- Revenue Analysis
- Inventory Movement Tracking
- Material Status Monitoring
- Customer Revenue Analysis

### Supporting Documentation

- ERP Process Flow Diagram
- Procure-to-Pay Workflow
- Order-to-Cash Workflow
- Inventory Integration Workflow

## Tools Used

- Python
- Excel
- Power BI

## Business Value

This project demonstrates ERP literacy, procurement process understanding, inventory management knowledge, and end-to-end supply chain process integration. It simulates how enterprise systems support operational decision-making across procurement, inventory, sales, and finance functions.
