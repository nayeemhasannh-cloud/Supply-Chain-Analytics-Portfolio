# Supply Chain Scenario Planning and Inventory Segmentation System

## Overview

This project combines inventory segmentation and scenario planning to improve inventory decision-making under uncertainty. The project classifies products based on value and demand variability while evaluating supply chain performance under multiple disruption scenarios.

## Module 1: Inventory Segmentation Using ABC-XYZ Analysis

### Business Problem

Not all inventory items require the same management strategy. High-value products and products with unstable demand require different inventory policies.

### Methods Used

#### ABC Analysis
Products were classified according to Annual Consumption Value.

Classes:
- A: High-value products
- B: Medium-value products
- C: Low-value products

#### XYZ Analysis
Products were classified according to demand variability.

Classes:
- X: Stable demand
- Y: Moderate variability
- Z: Highly variable demand

#### Combined ABC-XYZ Matrix

The two methods were combined to create strategic inventory segments and inventory control policies.

### Outputs

- Annual Consumption Value
- ABC Classification
- XYZ Classification
- Combined ABC-XYZ Matrix
- Inventory Policy Recommendations

### Visualizations

- Product Value Contribution Analysis
- ABC Product Distribution
- XYZ Demand Variability Distribution
- ABC-XYZ Heatmap
- Inventory Segment Distribution

### Dashboard Features

- Inventory Segmentation Dashboard
- Top Products by Inventory Value
- Inventory Value Monitoring
- Demand Analysis
- Recommended Inventory Policies
- Executive Insights
