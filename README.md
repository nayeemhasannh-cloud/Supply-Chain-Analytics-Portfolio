# Supply Chain Analytics Portfolio

## Overview
This repository contains a structured set of supply chain analytics projects covering forecasting, optimization, simulation, supplier analytics, and ERP process modeling. The objective is to apply data-driven decision-making to core supply chain problems using Python, Excel, and Power BI.

Each project focuses on a specific business problem and demonstrates how analytics improves cost efficiency, service level, and operational performance.

## Projects Included

### Project 1: Demand Forecasting & Inventory Optimization
Focus:
- Demand trend analysis and forecasting
- Inventory optimization using EOQ and safety stock
- Reorder point calculations

Tools:
Python, Excel, Power BI

Outcome:
Improves stock availability while minimizing holding costs.

### Project 2: Network Design & Logistics Optimization
Focus:
- Facility location analysis
- Transportation and routing optimization

Tools:
Python, Excel, Power BI

Outcome:
Reduces transportation cost and improves distribution efficiency.

### Project 3: Scenario Simulation & ABC/XYZ Segmentation
Focus:
- Product segmentation (ABC/XYZ analysis)
- Demand shock simulation
- Supply disruption risk analysis

Tools:
Python, Excel, Power BI

Outcome:
Improves risk awareness and inventory prioritization.

### Project 4: Supplier Scorecard & Vendor Analytics
Focus:
- Supplier performance evaluation
- Weighted scoring models
- Vendor risk and efficiency analysis

Tools:
Python, Excel, Power BI

Outcome:
Improves supplier selection and procurement decisions.

### Project 5: SAP ERP Process Simulation
Focus:
- Procurement and operational process mapping
- ERP workflow simulation
- KPI tracking

Tools:
Excel, Documentation

Outcome:
Improves understanding of end-to-end ERP-driven supply chain processes.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- Excel (Data analysis and modeling)
- Power BI (Dashboards and visualization)
