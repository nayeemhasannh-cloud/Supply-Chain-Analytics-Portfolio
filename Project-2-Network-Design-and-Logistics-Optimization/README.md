# Supply Chain Network Design and Logistics Optimization Engine

## Overview

This project combines logistics optimization and supply chain network design into a unified decision-support framework. The objective is to improve supplier performance evaluation, optimize transportation decisions, and design an efficient distribution network.

## Module 1: Logistics Optimization

### Business Problem

Supply chain managers must evaluate supplier performance using multiple criteria while balancing cost, quality, delivery performance, and risk.

### Data Processing

Raw supplier data was generated and transformed into decision-ready KPIs.

Key performance indicators were normalized to a 0–100 scale to ensure consistent evaluation across suppliers.

### Methods Used

- KPI Normalization
- Weighted Supplier Scoring
- Supplier Segmentation
- AHP (Analytic Hierarchy Process)
- Supplier Ranking
- Sensitivity Analysis
- Risk Stress Simulation

### Supplier Segmentation

Suppliers were classified into:

- Top Performers
- Medium Performers
- Low Performers

### Visualizations

- Supplier Score Distribution
- Top 10 Supplier Analysis
- Average Score by Supplier Category
- Initial Rank vs AHP Rank
- AHP Score vs Cost-Heavy Score
- Stress Test Score Distribution
- Defect Rate vs Quality Score
- Supplier Final Score Distribution

### Dashboard Outputs

- Supplier Segmentation
- Category-wise Performance
- On-Time Delivery Analysis
- Top and Bottom Suppliers
- Risk vs Performance Trade-Off Map
- Action Recommendation Table
